# 甩尾卡丁車 Drift Kart

瀏覽器上的 3D 卡丁車競速遊戲：6 台性能不同的車、4 條有髮夾彎、上下坡和跳台的賽道，可以跟電腦比賽，也可以用房間代碼和朋友連線對戰。

**開始玩：** https://871201billy-dev.github.io/drift-kart/

## 操作

| 按鍵 | 功能 |
|---|---|
| ↑ / W | 加速（放開會中斷氮氣） |
| ↓ / S | 煞車、倒車 |
| ← → / A D | 轉向 |
| Shift | 起甩（按越久甩越大） |
| Space / Ctrl | 氮氣 |
| R | 復位 |
| Esc | 選單 |
| M | 靜音 |

## 多人連線

選「多人連線」→「建立新房間」，把 4 碼房間代碼傳給朋友，朋友輸入代碼加入，房主按開始。連線使用 PeerJS 點對點傳輸，建立房間的人要留在頁面上，房間才會存在。部分公司或學校網路會擋點對點連線。
